## Назначение

Здесь лежат числа единственного уровня прототипа. Те же значения записаны в `src/data/balance.ts`. Это черновик для проверки цикла «набрал воду — посадил — собрал — продал», а не баланс кампании. Мясных цен нет: на M1 мясного содержания нет.

Луг — прямоугольник 1000×1000 условных единиц. Скорости ниже даны в этих единицах за секунду: 180 единиц в секунду — это пересечь луг примерно за 5,5 с.

## Колодец

| Параметр | Значение |
| --- | --- |
| Запас вёдер | 5 |
| Вёдер в начале | 5 (колодец полный) |
| Цена одного набора | 1 |
| Сколько набирается одно ведро | 1,3 с |

Пока ведро набирается, второй набор не начинается. Плата списывается в момент нажатия. Без монет и без запаса траву посадить нельзя.

## Яйцо на земле

| Параметр | Значение |
| --- | --- |
| Лежит, пока его не соберут | 14 с |
| Мигает перед тем как пропасть | последние 3,5 с |
| Зона нажатия по яйцу или клетке | 92 |

Медведь может испортить яйцо раньше, если подойдёт близко. Клетка по этим правилам не пропадает: у неё свой побег.

## Склад, рынок, клетка

| Параметр | Значение |
| --- | --- |
| Слоты склада | 8 |
| Слотов на одну клетку | 3 |
| Вместимость грузовика | 6 слотов |
| Рейс грузовика | 4,5 с |
| Цена яйца | 4 |
| Цена клетки | 18 |
| Клетка лежит на земле, потом медведь вырывается | 10 с |
| Клетка мигает перед побегом | последние 3 с |

Яйцо занимает один слот и в складе, и в кузове. Клетка занимает три. В кузов она встаёт только целиком: если свободных слотов меньше трёх, грузится то, что влезает, а клетка остаётся на складе. 18 монет за три слота выгоднее, чем три яйца (12), но цель уровня всё равно считается по яйцам.

## Медведь

| Параметр | Значение |
| --- | --- |
| Первый выход | через 25 с |
| Следующий выход | через 20 с после того, как клетку забрали на склад или медведь ушёл сам |
| Нажатий, чтобы посадить в клетку | 5 |
| Зона нажатия по медведю | 120 |
| Сколько бродит, если не поймать | 12 с |
| Портит яйцо, если оно ближе | 90 |
| Как часто портит | раз в 2 с |
| Скорость, когда ищет яйцо | 108 |
| Скорость, когда просто бродит | 64 |
| Как часто выбирает новое направление | 0,8 с |

Пока на земле лежит клетка, новый медведь не выходит. Если клетку не забрали и зверь вырвался, это тот же медведь: серию нажатий нужно начинать заново. Пока медведь на поле, куры в панике: не едят и не несутся, убегают от него. Голод при этом идёт.
