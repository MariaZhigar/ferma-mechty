## Назначение

Здесь лежат числа единственного уровня прототипа. Те же значения записаны в `src/data/balance.ts`. Это черновик для проверки цикла «посадил — собрал — продал», а не баланс кампании. Мясных цен нет: на M1 мясного содержания нет.

## Медведь

| Параметр | Значение |
| --- | --- |
| Первый выход | через 25 с |
| Следующий выход | через 20 с после клетки или ухода |
| Нажатий, чтобы посадить в клетку | 5 |
| Сколько бродит, если не поймать | 12 с |
| Портит яйцо на земле | раз в 2 с |
| Шаг медведя | 0,7 с |

Пока медведь на поле, куры в панике: не едят и не несутся, отходят от него. Голод при этом идёт.

## Уровень

| Параметр | Значение |
| --- | --- |
| Длительность | 3 мин |
| Цель | продать 6 яиц |
| Золото, если осталось не меньше | 70 с |
| Серебро, если осталось не меньше | 25 с |
| Иначе при победе | бронза |

Поражение — таймер вышел, цель не выполнена. Пороги медалей здесь только для этого уровня; кампания медалей — этап M2.
