# Ферма Мечты

Казуальная ферма в браузере: посадить, собрать, продать. Это личный проект Марии Жигар. Правила и план лежат в [`docs/`](docs/).

Сейчас это прототип этапа M1: одно поле, курица, яйца, склад, грузовик и медведь. Меню называется «Ферма Мечты».

## Как играть

Нажмите «Новая игра». В колодце уже есть вода: тап по лугу сажает пятно травы и тратит ведро. Если вода кончилась, нажмите колодец — ведро набирается не сразу и стоит монету. Курица бродит сама и, проголодавшись, идёт к ближайшей траве. Яйца лежат на земле недолго и мигают перед тем, как пропасть. Тап по яйцу кладёт его на склад, если есть место. «Загрузить» и «Отправить» увозят товар на рынок: деньги приходят, когда грузовик вернётся. На них можно купить ещё одну курицу и воду. Цель уровня — продать 6 яиц, пока не вышло время. Медведь выходит по таймеру: по нему нужно нажать несколько раз, тогда он оказывается в клетке. Клетка занимает несколько мест склада и тоже продаётся грузовиком. Если её не забрать, медведь вырывается.

«Продолжить» возвращает незавершённый забег. Режим «Детский» включён по умолчанию; смена режима действует со следующей попытки. Язык и звук запоминаются на устройстве.

## Что нужно

- Node.js 22 или новее
- npm

## Установка

```bash
npm ci
```

## Запуск

```bash
npm run dev
```

Игра открывается по адресу `http://localhost:5173/ferma-mechty/`. Путь `/ferma-mechty/` совпадает с адресом на GitHub Pages, поэтому локально и в выкладке ассеты ищутся одинаково.

Чтобы открыть игру с телефона в одной сети с компьютером:

```bash
npm run dev -- --host
```

В консоли появится сетевой адрес вида `http://<ip-компьютера>:5173/ferma-mechty/`. Его и нужно открыть на телефоне.

## Проверки и сборка

```bash
npm run lint        # ESLint
npm run typecheck   # TypeScript strict, без сборки
npm test            # Vitest
npm run test:watch  # тесты в наблюдении
npm run format      # записать форматирование Prettier
npm run build       # продакшен-сборка в dist/
npm run preview     # посмотреть сборку
```

Просмотр сборки: `http://localhost:4173/ferma-mechty/`.

## GitHub Pages

Сборка публикуется GitHub Actions при пуше в `main`: job выкладывает `dist/` через `actions/deploy-pages`. Базовый путь Vite — `/ferma-mechty/`.

**Один раз вручную.** Токен workflow не может включить Pages сам. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. Пока источник не переключён, деплой не заработает. После первого включения повторно менять его не нужно.

После первой загрузки с сетью игра открывается без интернета: service worker кладёт оболочку в кэш. Новая версия сама сменяет старый worker. На меню страница перезагружается, во время забега появляется плашка «Доступно обновление».

Если после выкладки всё ещё видно старое меню, закройте вкладку и откройте сайт ещё раз. Если и тогда старое: в Edge откройте средства разработчика → Application → Service Workers → Unregister и обновите страницу. После этой сборки так делать больше не нужно.
