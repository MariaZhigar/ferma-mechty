# Ферма Мечты

Казуальная ферма в браузере: посадить, собрать, продать. Это личный проект Марии Жигар. Правила и план лежат в [`docs/`](docs/).

Сейчас готов каркас (этап M0): стартовое меню «Ферма Мечты», переключатель русского и английского, локальные настройки и офлайн-оболочка. Игрового поля ещё нет — оно начнётся с этапа M1.

## Что нужно

- Node.js 22 или новее
- npm

## Установка

```bash
npm ci
```

## Запуск

```bash
npm run dev
```

Игра открывается по адресу `http://localhost:5173/ferma-mechty/`. Путь `/ferma-mechty/` совпадает с адресом на GitHub Pages, поэтому локально и в выкладке ассеты ищутся одинаково.

Чтобы открыть игру с телефона в одной сети с компьютером:

```bash
npm run dev -- --host
```

В консоли появится сетевой адрес вида `http://<ip-компьютера>:5173/ferma-mechty/`. Его и нужно открыть на телефоне.

## Проверки и сборка

```bash
npm run lint        # ESLint
npm run typecheck   # TypeScript strict, без сборки
npm test            # Vitest
npm run test:watch  # тесты в наблюдении
npm run format      # записать форматирование Prettier
npm run build       # продакшен-сборка в dist/
npm run preview     # посмотреть сборку
```

Просмотр сборки: `http://localhost:4173/ferma-mechty/`.

## GitHub Pages

Сборка публикуется GitHub Actions при пуше в `main`: job выкладывает `dist/` через `actions/deploy-pages`. Базовый путь Vite — `/ferma-mechty/`.

**Один раз вручную.** Токен workflow не может включить Pages сам. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. Пока источник не переключён, деплой не заработает. После первого включения повторно менять его не нужно.

После первой загрузки с сетью игра открывается без интернета: service worker кладёт оболочку в кэш. Новая версия подхватывается на экране меню, а не посреди будущего уровня.
